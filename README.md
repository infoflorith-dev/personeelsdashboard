# Personeelsdashboard

Dashboard voor analyse van:

- Ziekteverzuim
- Vakantiedagen
- Tijd voor tijd
- Buitengewoon verlof
- Overige afwezigheid

Functies:

- Excel upload
- Werkdagen berekenen (zonder weekenden)
- Dashboard met grafieken
- Top 10 afwezigen
- Detailoverzicht per medewerker
- Lokale opslag (geen database)
